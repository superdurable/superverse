# Contributing

We do not accept code contributions at this time. Pull requests will be closed.

Bug reports and feature requests are welcome as [GitHub issues](https://github.com/superdurable/superverse/issues). For a bug, include what you expected, what happened, steps to reproduce it, the Superverse version or commit, and relevant error messages with credentials and personal data removed. For a feature request, describe the use case and the behavior you need.

Report security problems privately through [GitHub private vulnerability reporting](https://github.com/superdurable/superverse/security/advisories/new). Do not post them as public issues.
