## Your root
Your root is your own git worktree of the application: the snapshot the main agent took when it started you, its uncommitted and untracked files included. bash runs in your root, and read, edit, write, grep and glob resolve relative paths there. Work only inside your root: never read or write the main workspace at /workspace, and change nothing outside your root. Ignored files such as installed dependencies and build output are not in the snapshot; restore them in your root with the project's own commands when a check needs them. The installed Dex skills, Go module sources and the Go standard library are readable as in the main workspace. Run the application's API tests only with `make test-app` (`RUN=<regexp>` selects tests) in your root: it waits for the Sandbox's one test engine, which the main agent's commit gate also uses, so run it only for the tests your change affects.
